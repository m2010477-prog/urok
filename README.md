# Halloween Story Lab

Конструктор одного общего промпта для нейросети. По нему модель в **одном ответе** сначала создаёт методически обоснованный текстовый план **трёх уроков**, затем ниже — **три отдельных самодостаточных промпта** для генерации трёх тетрадей. Один промпт тетради = одна тетрадь = один урок.

## Как пользоваться

1. Откройте `index.html`, задайте параметры и нажмите «Собрать общий промпт».
2. Скопируйте общий промпт и отправьте его текстовой нейросети.
3. Получите в одном ответе паспорт курса, общую историю, педагогический план трёх уроков и три промпта тетрадей ниже плана.
4. Проверьте план. Если вносите изменения, попросите модель обновить также все затронутые промпты.
5. Отправьте каждый промпт тетради в модель, которая умеет создавать выбранный формат файлов. Их можно использовать в отдельных чатах: нужные параметры и сюжетный контекст должны быть включены в каждый промпт.
6. Проверьте созданные тетради перед занятием.

На первом этапе модель не должна создавать сами тетради. Конструктор не обращается к нейросети и не создаёт PDF или HTML-тетради автоматически: он составляет общий промпт.

## Педагогический дизайн

Промпт требует проектировать от результата: измеримые цели → доказательства достижения → задания и поддержка. В плане предусмотрены входная диагностика, извлечение из памяти, последовательная практика, постепенное снятие опор, перенос, текущая проверка и рубрика финального проекта. Для каждого урока — конкретные языковые цели, сюжетные факты, материалы и поминутный план. Три будущие тетради должны точно соответствовать этому плану.

## Настройки

- Возраст и уровень вводятся вручную.
- Один или несколько навыков: лексика, грамматика, чтение, аудирование, письмо, говорение.
- 18 завязок, 12 атмосфер, 16 финальных проектов, 10 стилей иллюстраций.
- PDF для печати или интерактивная HTML-тетрадь с автопроверкой.
- Длительность, формат занятия, дополнительные условия.

## Проверка ответов

В промптах тетрадей требуется: сначала подумать, затем выбрать и подтвердить ответ уликой или правилом. Один выбранный вариант не достаточен для зачёта. Математическую невозможность угадывания конструктор не обещает.

Для интерактивных тетрадей проверяемые поля должны иметь реальную автопроверку, обратную связь и повторную попытку. Свободное письмо и речь без внешнего ИИ требуют оценки преподавателя; для них предусмотрены рубрика и автопроверяемые микрозадания. Ключи локального HTML видны в исходном коде; это не защищённый экзамен.

Генерация PDF, изображений и аудио зависит от инструментов выбранной модели. При их отсутствии промпт требует честный резервный формат — полный печатный макет, HTML-код, схемы или сценарий озвучки.

## Публикация на GitHub Pages

1. Создайте репозиторий, например `halloween-story-lab`.
2. Загрузите содержимое папки проекта в корень: `index.html`, `style.css`, `app.js`, `README.md`, `LICENSE`, `.nojekyll`.
3. В **Settings → Pages** выберите публикацию из ветки и папку **/(root)**.
4. Откройте адрес, показанный GitHub после публикации.

Сборка, зависимости и API-ключи не нужны. Пакет не подключён к аккаунту GitHub и автоматически не публикуется. При запрете копирования локального файла текст выделяется для Ctrl+C / ⌘C.

Проверены синтаксис JavaScript, формирование общего промпта для обоих форматов и разных наборов навыков, порядок плана и трёх промптов, перенос параметров и обновлённые элементы интерфейса. Визуальная проверка браузера не выполнена. Перед публикацией проверьте копирование, скачивание, сброс, выбор навыков и мобильную версию.

Данные формы не отправляются серверу и не сохраняются после перезагрузки. Google Fonts загружает шрифты из сети; без сети используются системные шрифты. Лицензия MIT.

## Только студенческие тетради

Все три промпта создают только тетради ученика: материалы, задания и поля ответов. Ответы, ключи, заметки преподавателя, тайминг, сценарии озвучки, рубрики и спойлеры остаются в первоначальном текстовом ответе модели. Учительские тетради, приложения и файлы не создаются. Для соответствия ключей задания фиксируются в первоначальном ответе со стабильными номерами и переносятся в промпты без ответов.

В интерактивной тетради нет показа правильных решений или учительских разделов; автопроверка содержит лишь необходимую техническую логику внутри кода. Её можно изучить в исходном файле: полностью убрать проверочные данные из локального HTML и одновременно сохранить автономную автопроверку невозможно.

## Случайный промпт

Кнопка «Случайный промпт» выбирает один из 15 готовых вариантов, заполняет все параметры и сразу создаёт общий промпт. Два нажатия подряд не выбирают тот же вариант. Настройки можно изменить и снова нажать «Собрать общий промпт». При публикации загрузите также `presets.js` рядом с `app.js`.
